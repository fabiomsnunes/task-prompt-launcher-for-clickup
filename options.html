Task Prompt Launcher for ClickUp

Templates for the prompts built from the button on ClickUp tasks. Click a shortcode to insert it where the cursor is.

With the ClickUp MCP connected, the ID is enough: Claude Code fetches the description, subtasks and comments itself.
